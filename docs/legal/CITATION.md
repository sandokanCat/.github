# Citing this repository

The machine-readable citation metadata is maintained in the root-level [CITATION.cff](../../CITATION.cff). GitHub uses that file to provide the repository citation interface, so it must remain at the repository root.

Keep the author, title, version, release date, and commit in CITATION.cff consistent with the release being described. Do not invent or copy a DOI from another version.

## Zenodo DOIs

When the GitHub–Zenodo integration has archived a release, record the verified DOI for that exact version in CITATION.cff. Zenodo also provides a concept DOI that represents the project across versions. Use the version-specific DOI when citing a particular release; use the concept DOI when referring to the evolving project as a whole. Confirm both values on the Zenodo record page before adding them to repository metadata.

A GitHub release and a Zenodo record are separate publication events. Publishing a GitHub release does not prove that Zenodo has finished archiving it or minted a DOI.
